## 만든 이유
React 학습용으로 
정적 HTML로 만들어진 아파트 분양 안내 사이트를 React + TypeScript로 다시 만든 클론 프로젝트. 마크업을 컴포넌트 단위로 쪼개고 라우팅을 붙이며, 실무형 정적 페이지를 React로 옮기는 과정을 연습했다


## 주요 기능
- 정적 HTML/CSS로 되어 있던 페이지를 섹션·컴포넌트 단위로 분해해 재사용 가능한 React 컴포넌트로 재구성
- React Router로 단지 안내, 위치, 커뮤니티 등 섹션형 페이지 간 라우팅 구현
- 다양한 화면 너비에 대응하는 반응형 레이아웃 적용
- vercel로 빌드·배포
