## 만든 이유
- SEO를 토대로 AEO·GEO가 쌓이는 구조를 바탕으로, 아래 단계 항목을 전제로 체계적 진단 제공
- 표준·연구 문서·구글 공식 지침 등 근거가 명확하고 검증된 항목 기반의 객관적 분석
- URL 입력만으로 SEO · AEO · GEO 항목을 자동 채점해주는 무료 진단 서비스 구축

## 기술스택
- Next.js App Router
- TypeScript
- Tailwind CSS
- Vercel

## 주요 기능
- **URL 기반 자동 진단 및 채점**: 웹사이트 URL을 입력하면 SEO · AEO · GEO 항목을 자동 분석하고 점수화하여 제공
- **단계별 3단 진단 체계**: SEO 기본 레이어 위에 AEO 및 GEO 진단 항목이 수직적으로 결합된 구조 적용
- **근거 중심의 검증 항목**: 웹 표준, 구글 문서 및 연구 결과 등 공통으로 인정받는 진단 기준 적용
- **직관적인 분석 결과 UI**: Tailwind CSS를 활용하여 영역별 진단 결과를 한눈에 파악할 수 있는 대시보드 제공
- **Next.js App Router 기반 성능 최적화**: 서버 사이드 기능을 활용한 빠른 분석과 최적화된 사용자 경험 제공
