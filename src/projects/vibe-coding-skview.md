## 만든 이유
React 프로젝트를 Claude Code AI를 활용해서 바이브 코딩으로 만들어보고, 직접 짤 때와 무엇이 다른지 체감해보고 싶었다.

## 주요 기능
- Claude Code에 요청 → 결과 확인 → 다음 요청으로 이어가는 방식으로 페이지 구현
- React Router로 페이지 간 이동 구현
- 반응형 레이아웃 적용
- Vercel로 배포

## 느낀 점
AI가 코드를 빠르게 만들어주긴 하지만, 결과물이 의도한 대로인지 확인하고 필요하면 직접 고치는 몫은 여전히 남는다는 걸 체감했다.
